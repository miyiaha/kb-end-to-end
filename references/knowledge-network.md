# 知识网络层实现手册（Knowledge Network Playbook）

> 版本：v1.5（2026-09-06）｜ 对应白皮书 F13–F16 与方案 0「知识网络升级」
> 定位：把「文件仓库」升级为「知识网络」——相似内容自动聚拢、资料建立关联、按问题检索、答案可溯源、每周清重、月度主题总结。
> 适用载体：飞书云盘索引库（多维表格）、Obsidian 库、企业网盘；以下方法全部本地算法，零外部 API，文档内容不出库。

---

## 1. 为什么需要知识网络层（设计逻辑）

治理完成不等于知识可用：相似内容仍分散在不同目录、资料之间没有联系、找答案靠逐个翻文件。三个本质问题：

| 问题 | 表现 | 后果 |
|------|------|------|
| 相似无感知 | 同名/近名文件散落多处 | 重复副本悄悄堆积，人眼发现不了 |
| 关联不可见 | 方案、纪要、数据互不引用 | 知识孤岛，跨资料联系靠记忆 |
| 检索靠碰运气 | 只能关键词搜索，语义近的查不到 | 答案定位不了证据，可信度低 |

知识网络层用「指纹 → 聚类 → 关联 → 检索 → 清重」五步把仓库变成可计算的网络。

## 2. 内容指纹引擎（F13）

### 2.1 目的
把每条文档变成可计算的向量，让机器"看出"知识之间的语义距离。

### 2.2 实现方法（本地算法）
- **A 向量（关键词权重）**：jieba 分词 + TF-IDF，捕捉"哪些词更能代表这篇文档"
- **B 向量（字面结构）**：字符 n-gram 2-3 元，捕捉"字面长什么样"，对同义词/短文本更鲁棒
- **拼接**：两向量各自 L2 归一化后拼接为混合指纹
- **规模实测**：302 条 × 4366 维（词表 1223 + n-gram 3143），秒级算完
- **增量维护**：新入库文档只算新向量，不重算全量
- **输入**：第一阶段 = 标题 + 摘要 + 主题（正文逐步补充，避免一次性导入）

### 2.3 质量要点
- 标题相同但内容差异大的（如历史版本 vs 现行版）会自然分到低相似度——不能只看文件名
- 指纹只在本库本地计算，**不上传任何外部 embedding API**（隐私硬约束）

## 3. 相似聚类与知识关联（F14）

### 3.1 三档阈值
两两余弦相似度聚类，按档位分流：

| 档位 | 阈值 | 语义 | 处置 |
|------|------|------|------|
| 重复 | > 0.92 | 基本同一内容 | 出待裁决 / 命中 D7 自动清理 |
| 相似 | 0.85 – 0.92 | 高度相似，可能同主题不同版本 | 出待裁决 |
| 相关 | 0.75 – 0.85 | 主题相关，可互链 | 建立「相关文档」边，不裁决 |

> 阈值按真实数据校准，不是拍脑袋。首次全量聚类后人工复核一批，再微调阈值。

### 3.2 聚类输出
- 每组合并展示：成员、相似度、生命周期、保护标记、处置建议
- 结合索引 topics 字段建立「相关文档」边，形成知识关联网络（供驾驶舱"相关内容"入口）

### 3.3 特殊判定规则
- **保护命中**（见 §5）：只标注，绝不裁决
- **会议纪要多产物**（智能纪要/文字记录/AI视图）：判定为互补，建议保留+互链，不裁决
- **版本链**（V3/V2）、合同系列对：建议保留
- **标题同内容异**（如卡拉杰克）：相似度低但仍需人工核验

## 4. 可信检索问答（F15）

### 4.1 混合检索
- **BM25 关键词检索 + 向量语义检索**，权重 **6:4**
- 召回 Top-K 文档 → 读原文定位命中片段 → 返回答案
- 每条答案标注**原文位置（文档名 + 章节/段落）**，可点开复核
- 检索入口：对话直问 + 驾驶舱集成两种形态

### 4.2 答案溯源格式
```
答案正文……
来源：[文档名](链接) · 章节位置：第 X 章 / 第 X 段
```
- 无来源不答；拿不准时明说"未找到可靠出处"
- 引用正确率目标 ≥90%，响应 <10 秒（v2.0 评测集验收）

## 5. 保护机制（D6，强制）

以下四类文件自动检测并**跳过一切清理/修改动作**（检索仍可读）：

| # | 保护规则 | 判定方式 |
|---|---------|---------|
| 1 | 01_项目 目录全部文档 | 位置前缀 |
| 2 | lifecycle=进行中项目（编制中/草稿/评审中/待发布） | 生命周期字段 |
| 3 | 公司标准文件 | [标准] 前缀 / 名称含 标准·规范·制度·规程·指引 |
| 4 | 手动标注「保护」 | 状态/备注字段人工标记 |

- 保护清单**绝不触发清理**，即使相似度命中重复档也只作关联标注
- 判定口径宁多勿少（本项目 87 条标保护）

## 6. 自动清理授权（D7，强制边界）

**可自动处理**（无需逐条确认）：
- 标题重复 + 内容完全一致（正文逐段比对无差异）+ 完全把握
- 处理：保留规范正本，副本移 99_回收区 + 删索引记录（**非物理删除，可找回**）
- 事后在每日巡检记录「自动清理清单」区块标识告知

**绝不自动**：
- 保护清单命中
- 有实质差异（相似≠相同）
- 任何物理删除 / 改正文

## 7. 每周清重 + 月度主题总结（F16）

### 7.1 每周清重
- 触发：周五入库完成后自动跑
- 动作：增量向量化 + 相似检测 → 命中 D7 按规则处理并在巡检「自动清理清单」告知 → 其余出待裁决清单
- 验收：零漏检、零误删

### 7.2 月度主题总结
- 月度保鲜升级为主题总结报告：按板块聚类 → 串起本月零散知识 → 点出跨资料联系 → 输出 HTML 报告
- 验收：每月 1 份

## 8. 落地清单（给执行 Agent）

```text
[ ] 建立索引库 12 字段（名称/类型/主题/知识类型/状态/生命周期/优先级/调用次数/更新时间/位置/链接/摘要）
[ ] 全量拉取索引记录（名称+摘要+主题作为指纹输入）
[ ] 构建向量库：jieba+TF-IDF A向量 + n-gram B向量，L2 归一化拼接
[ ] 两两相似度聚类（重复>0.92/相似0.85-0.92/相关0.75-0.85）
[ ] 标记保护组（D6 四类），聚类结果跳过保护组裁决
[ ] 输出待裁决清单（只出清单不动文件），逐项附相似度+建议
[ ] 会议纪要多产物→互补保留+互链；版本链/合同对→建议保留
[ ] 上线混合检索（BM25+向量 6:4）+ 答案溯源
[ ] 每周五增量向量化+相似检测；月度主题总结
```

## 9. 与基础闭环的关系

知识网络层不替代六环节闭环（入库→打标→分类→调用复核→复盘→标准迭代），而是**在调用复核环新增"知识网络"维度**：每周清重输出进入⑤复盘改进，月度主题总结进入⑥标准迭代，形成新回流线——知识网络每月重组一次、串讲一次。
